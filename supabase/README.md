# supabase — DB

| 폴더 | 내용 |
|---|---|
| `migrations/` | 표를 만드는 SQL. 번호 순서대로 (예: `001_tables.sql`) |
| `seed/` | 처음 직접 넣을 데이터: 장소 10~15곳, 소리 묶음표, 설정값 |

표 목록과 담을 내용은 `docs/04_구현_할일_데이터.md` 참고.
칸 이름 · 자료형이 정해지면 SQL과 문서를 같이 고친다.

권한 규칙:
- 기기 ID 기준으로 자기 기기 프로필과 방문만 읽고 쓰기
- 사업장 무던한 시간 표는 로그인 없이 쓰기 허용 (시연용)
