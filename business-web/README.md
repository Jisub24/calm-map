# business-web — 사업장 등록 웹

가게가 '무던한 시간대'를 등록 · 수정 · 삭제하면 보호자 앱 지도와 장소 상세에 표시된다.
로그인 없이 장소를 골라 바로 등록하는 시연용 (`docs/03_화면_구성.md` 8번).

## 화면

1. 장소 고르기 — 장소 표를 읽어 목록으로
2. 가게의 무던한 시간 — 등록된 목록, 수정 · 삭제
3. 등록 · 수정 — 요일 · 시간(30분 단위) · 하는 조치, 끝 시간 · 겹침 확인

## 기술

- Supabase JS로 `장소`, `사업장 무던한 시간` 표에 바로 읽고 쓰기. 서버 코드 없음
- React 또는 순수 HTML · JavaScript (미정)
- 무료 호스팅 (예: Vercel, Netlify)
- Supabase 주소와 anon key는 `.env`에. service key는 넣지 않는다
