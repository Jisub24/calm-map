# batch — 예약 계산 (Python)

GitHub Actions(`.github/workflows/`)로 정해진 간격마다 실행한다.

| 작업 | 주기 | 내용 |
|---|---|---|
| 혼잡도 수집 | 1시간 | 서울시 실시간 도시데이터에서 현재 혼잡도 + 향후 12시간 예측 저장 |
| 소리 묶음 · 점수 계산 | 10~15분 | 측정 라벨을 소리 종류 5개로 묶고 요소별 점수 계산 |
| 시간대별 예측 · 상태 판정 | 10~15분 | 오늘 1시간 단위 예측, 단계 / 추정 / 정보 부족 판정 |

계산 규칙은 `docs/04_구현_할일_데이터.md`의 "계산 규칙".
서울시 API 키와 Supabase service key는 GitHub Secrets에 둔다.
