# MVP 범위

## 만드는 것

- **보호자 앱 (Android)**: 첫 실행(시작 안내 · 위치 권한 · 민감 요인 등록), 지도, 장소 카드 · 장소 상세, 방문 확정, 다녀온 뒤 기록, 측정(측정 전 · 측정 중 · 측정 완료), 설정
- **사업장 등록 웹**: 장소 고르기, 가게의 무던한 시간 목록, 등록 · 수정 · 삭제 (로그인 없음)
- **서버**: 혼잡도 수집, 소리 묶음, 점수 계산, 시간대별 예측, 상태 판정
- 화면별 세부 요소는 `03_화면_구성.md`, 영역별 할 일은 `04_구현_할일_데이터.md`

## 만들지 않는 선택 기능

여유가 생겨도 기능 동결(10/25) 전에 팀이 합의한 경우에만 추가한다. 안 만든 것은 성과보고서 "개선방안"에 쓴다.

| 화면 | 기능 | 내용 |
|---|---|---|
| 민감 요인 등록 | 나중에 하기 | 건너뛰면 맞춤 없이 기본 점수로 시작 |
| 지도 | 시간 바꿔 보기 | 시간 슬라이더로 오늘 다른 시간 기준 표시 |
| 지도 | 업종 고르기 | 마트 · 카페 · 식당 · 병원 · 미용실 버튼으로 걸러 보기 |
| 지도 | 장소 목록 | 장소를 누르지 않고 아래에서 끌어올리면 가까운 순 목록 |
| 장소 카드 | 사업장 시간 표시 | 예측 그래프에서 사업장이 등록한 시간대 위에 작은 표시 |
| 장소 상세 | 다른 요일 보기 | 요일을 바꾸면 그 요일의 시간대별 예측 그래프 |
| 장소 상세 | 밝기 | 이 시간 측정된 밝기 단계 |
| 미리 보는 카드 | 카드 자동 생성 | 장소 정보로 3~4장을 만듦. ① 입구 사진 + "문을 밀고 들어가요" ② "계산대는 오른쪽이에요" ③ "소리가 크면 헤드폰을 써요" |
| 미리 보는 카드 | 상황별 카드 | 방문 시간 예측이 붐빔이거나 안내방송이 많을 것 같으면 헤드폰 카드를 앞쪽에 |
| 미리 보는 카드 | 아이 보기 모드 | 그림 크게, 글자 크게, 한 장씩 넘기기 |
| 미리 보는 카드 | 방문 시작 버튼 | 방문 중 화면으로 |
| 방문 중 | 화면 켜둠 안내 | "화면을 켜두면 주변을 계속 확인해요" |
| 방문 중 | 주변 감각부하 | 측정 기능으로 주변을 계속 확인하고 지금 단계를 표시 |
| 방문 중 | 급상승 알림 | 직전 1분보다 크게 오르면 보호자 폰 진동 |
| 방문 중 | 조용한 구역 안내 | 진동과 함께 "가까운 조용한 곳: 1층 수유실" |
| 방문 중 | 방문 끝 버튼 | 다녀온 뒤 기록으로 |
| 다녀온 뒤 기록 | 힘들었던 자극 | "힘들었어요"를 누르면 자극 목록에서 해당하는 것 체크 (건너뛰기 가능) |
| 다녀온 뒤 기록 | 맞춤 반영 | 기록을 그 방문 시간의 자극 구성과 묶어 민감 요인 가중치를 조금씩 조정 |
| 측정 전 | 거리 확인 | 현재 위치가 장소에서 200m 넘게 떨어져 있으면 "그래도 측정할까요?" |
| 측정 전 | 측정 자세 안내 | "화면이 위를 보게 들고 계세요" |
| 측정 중 | 밝기 | 조도센서 값(lux) |
| 측정 완료 | 전송 실패 시 | 결과만 기기에 보관했다가 나중에 다시 보내기 |
| 설정 | 앱 정보 | 버전, 공모전 출품작 안내 |
| 백 | 다른 요일 예측, 기종별 보정 계수 반영, 맞춤 가중치 자동 조정 | 데이터가 쌓이면 검토 |
| 사업장 웹 | 로그인 · 가입 신청 · 매장 정보 · 표시 켜고 끄기 | 로그인 없이 시연용으로만 만듦 |

## 제안서에는 있지만 이번에 안 하는 것

| 항목 | 제안서 내용 | 이유 · 대신 하는 것 |
|---|---|---|
| 지자체 · 복지관용 관리 콘솔 | 서비스 형태 중 하나 | 운영 단계 기능 |
| 사업장 로그인 · 사장 인증 | 사업장이 스스로 등록 | 진짜 사장인지 확인하는 절차는 기간 안에 어려움. 장소를 골라 바로 등록하는 형태로 시연하고, 운영 때 추가할 기능으로 성과보고서에 기재 |
| 배리어프리 인증 연계 | 사업장 참여를 지자체 인증 사업과 연계 | 운영 단계 일. 성과보고서에 계획으로 기재 |
| 형광등 깜빡임 판별 | 민감 요인 예시 | 폰 조도센서로는 깜빡임을 잴 수 없음. 밝기 측정도 이번에는 만들지 않음 |
| 제주 수기 지도 활용 | 초기 데이터 확보 1단계 (194곳) | 측정 지역인 서울과 다름. 문제정의의 근거로 인용 |
| 장소 30곳 | 구현 최소 기능의 범위 | 측정 시간 때문에 10~15곳으로 줄임 |
| 화면이 꺼진 상태의 측정 | 방문 중 계속 확인 | 방문 중 화면 자체를 이번에 만들지 않음 |
| 지역 확장 | 초기 데이터 확보 3단계 | 이번에는 한 동네로 한정 |
| 수익 모델 | 인증 · 노출, 데이터 제공 | 앱 기능이 아님. 성과보고서에만 기재 |
