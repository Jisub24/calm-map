# 화면 구성 (MVP)

이번 공모전에서 만드는 **필수 기능만** 정리한 문서. 선택 기능은 만들지 않는다 (목록은 `02_MVP_범위.md`).
"영역"은 그 요소 때문에 새로 만들 것이 있는 곳 (프론트 = 앱 또는 웹 화면, 백 = 서버, DB = 표).

와이어프레임: https://claude.ai/artifact/HpjZnZGUZd5TdgysyT6C9s (팀원 공유 필요)

## 0. 화면 이동 흐름

| 흐름 | 순서 |
|---|---|
| 처음 켰을 때 | 시작 안내 → 위치 권한 → 민감 요인 등록 → 지도 |
| 나가기 전 10초 | 지도 → 장소 누름 → 장소 카드 (권고 시간대 + 오늘 예측 그래프) → [자세히 보기] → 장소 상세 |
| 방문 | 장소 카드 · 상세 [방문하기] → 방문 확정 → 지도 (방문 예정 배너) → [다녀왔어요] → 다녀온 뒤 기록 → 지도 |
| 현장 측정 | 장소 상세 [이 장소 측정하기] → 측정 전 → 측정 중 (30초) → 측정 완료 → 장소 상세 |
| 설정 | 지도 톱니바퀴 → 설정 (민감 요인 수정 · 개인정보 안내) |
| 사업장 등록 (웹) | 장소 고르기 → 가게의 무던한 시간 목록 → 등록 · 수정 · 삭제 → 보호자 앱 지도와 장소 상세에 반영 |

**나가기 전 10초 원칙**: 앱을 열고 장소를 한 번 누르면 권고 시간대와 오늘 예측 그래프가 바로 보여야 한다.

### 예외 상황

| 상황 | 어디서 | 처리 |
|---|---|---|
| 위치 권한 거부 | 첫 실행 · 지도 | 측정 동네 중심으로 지도 표시, 내 위치 버튼 숨김 |
| 마이크 권한 거부 | 측정 전 | "마이크 권한이 있어야 해요" + 설정으로 이동. 지도와 예측 보기는 그대로 가능 |
| 측정이 부족한 장소 | 지도 · 장소 카드 | 혼잡도가 있으면 "추정", 없으면 "정보 부족"으로 표시하고 안내 문구도 그에 맞게 |
| 측정 중 앱을 벗어남 | 측정 중 | 측정 취소. 돌아오면 "측정이 중단됐어요" |
| 인터넷 끊김 | 모든 화면 | "인터넷 연결을 확인해 주세요" + 다시 시도 |
| 같은 요일에 시간이 겹침 | 사업장 웹 등록 | 저장 전에 겹치는 줄을 알려주고 고치게 함 |

## 1. 첫 실행

### 시작 안내

| 구성 요소 | 내용 | 영역 | 비고 |
|---|---|---|---|
| 서비스 소개 | "시간대별로 덜 붐비고 덜 시끄러운 때를 알려드려요" 같은 소개 1~2줄 | 프론트 |  |
| 개인정보 안내 | "주변 소리는 녹음·저장하지 않고 소리 종류만 확인합니다" | 프론트 | 설정 화면에도 같은 문구 |
| 시작 버튼 | 다음 단계로. 이때 기기 ID를 만들어 기기에 보관 | 프론트 | 로그인 대신 기기 ID |

### 위치 권한

| 구성 요소 | 내용 | 영역 | 비고 |
|---|---|---|---|
| 권한 요청 | 필요한 이유 한 줄(주변 장소 표시)을 먼저 보여주고 시스템 권한 창 | 프론트 |  |
| 거부했을 때 | 측정 동네 중심으로 지도를 열고 내 위치 버튼은 숨김 | 프론트 |  |

### 민감 요인 등록

| 구성 요소 | 내용 | 영역 | 비고 |
|---|---|---|---|
| 자극 고르기 | 소리: 안내방송 · 사람 말소리(웅성거림) · 음악 · 기계음/경보음 · 갑작스러운 큰 소리 / 혼잡: 사람이 많음 | 프론트 |  |
| 힘든 순서 정하기 | 고른 자극을 끌어서 순서를 정함 (예: 안내방송 > 사람 소리) | 프론트 | 순서별 가중치 값은 DB 설정값에서 가져옴 |
| 완료 | 기기에 저장하고 서버의 기기 프로필에도 저장한 뒤 지도로 | 프론트 · DB | 아이 이름 · 나이 · 진단명은 받지 않음 |

## 2. 지도 (메인 화면)

### 기본 화면

| 구성 요소 | 내용 | 영역 | 비고 |
|---|---|---|---|
| 지도 | 측정 동네의 장소 10~15곳이 한 화면에 다 들어오는 범위로 시작 | 프론트 | 네이버 또는 카카오 지도 |
| 장소 표시 | 무던함 · 보통 · 붐빔을 진하기 3단계로, 표시 아래에 "무던" "보통" "붐빔" 글자 | 프론트 · 백 · DB | 색이 아니라 진하기 + 글자 |
| 추정 표시 | 소리 측정은 부족하지만 혼잡도 정보는 있는 장소. 테두리만 있는 표시 + "추정" | 프론트 · 백 · DB | 제안서 2단계: 혼잡도로 지도 골격을 먼저 채움 |
| 정보 부족 표시 | 측정도 혼잡도도 없는 장소. 회색 + 점선 테두리, "정보 부족" | 프론트 · 백 · DB |  |
| 범례 | 무던함 · 보통 · 붐빔 · 추정 · 정보 부족 설명 | 프론트 |  |
| 기준 시각 | 위쪽에 "지금 15:20 기준" | 프론트 |  |
| 우리 아이 맞춤 | 위쪽 오른쪽 스위치. 켜면 장소 표시가 바로 바뀜. 장소 카드의 스위치와 같은 상태 | 프론트 · DB | 영상 핵심 장면 |
| 방문 예정 배너 | 방문을 확정한 장소가 있으면 위쪽에 "OO마트 15시 방문 예정 · [다녀왔어요]" | 프론트 · DB | 다녀온 뒤 기록으로 가는 길 |
| 내 위치 버튼 | 누르면 현재 위치로 이동 | 프론트 |  |
| 설정 버튼 | 오른쪽 위 톱니바퀴 | 프론트 |  |
| 사업장 표시 | 사업장 웹에서 무던한 시간대를 등록한 가게에 작은 표시. 지금이 그 시간이면 "무던한 시간 운영 중" | 프론트 | 영상: 웹에서 등록 → 앱 지도에 표시되는 장면 |

### 이어지는 화면

| 구성 요소 | 내용 | 영역 | 비고 |
|---|---|---|---|
| 장소 카드 | 장소를 누르면 바로 아래에서 올라옴. 오늘 시간대별 예측 그래프가 여기에 있음 | 프론트 | 자세한 구성은 3번 |
| 불러오기 실패 | "장소 정보를 불러오지 못했어요" + 다시 시도 | 프론트 |  |

## 3. 장소 카드 · 장소 상세

### 장소 카드 / 장소를 누르면 바로

| 구성 요소 | 내용 | 영역 | 비고 |
|---|---|---|---|
| 장소 이름 | 장소명, 업종, 내 위치에서 거리 | 프론트 · DB |  |
| 권고 시간대 | "오늘은 14시 이후가 무던합니다"를 카드에서 가장 크게 | 프론트 · DB | 점수보다 무던한 시간을 앞에 둠 (제안서 원칙) |
| 권고 문구 예외 | 무던한 시간이 없으면 "오늘은 무던한 시간대가 확인되지 않았어요" / 정보가 부족하면 "아직 측정이 부족해서 안내하기 어려워요" | 프론트 | "가면 안 돼요" 같은 판정형 금지 |
| 오늘 시간대별 예측 그래프 | 오늘 영업시간을 1시간 단위 막대로. 지나간 시간은 진하게, 앞으로의 시간은 예측이라 옅게. 막대 진하기가 단계 | 프론트 · 백 · DB | 제안서: 장소를 누르면 오늘 하루의 시간대별 예측 그래프 |
| 지금 표시 | 현재 시간 막대 위에 "지금" | 프론트 |  |
| 정보 부족 시간 | 측정도 혼잡도 예측도 없는 시간은 회색 빗금 + "정보 부족" | 프론트 · 백 · DB |  |
| 우리 아이 맞춤 | 스위치. 켜면 그래프와 권고 시간이 바로 다시 계산됨 | 프론트 · DB | 영상 핵심 장면 |
| 버튼 | [방문하기] [자세히 보기] | 프론트 | 카드를 위로 끌어올려도 상세로 |

### 장소 상세 / 카드를 끌어올리면

| 구성 요소 | 내용 | 영역 | 비고 |
|---|---|---|---|
| 지금 상태 | 지금 시간의 단계를 글자로 크게, 점수(0~100)는 작게 | 프론트 · DB |  |
| 소리 구성 | 이 시간에 많이 들린 소리 종류 3개를 막대로 (예: 사람 말소리 많음 · 음악 보통) | 프론트 · 백 · DB | 점수가 왜 그렇게 나왔는지 보여주는 부분 |
| 혼잡도 | 이 시간 혼잡도 단계 + "신촌 지역 기준" 표시 | 프론트 · 백 · DB | 혼잡도는 가게가 아니라 지역 단위 |
| 측정 근거 | "이 시간대 측정 2회 · 마지막 측정 10/12 15:40" | 프론트 · DB | 정보 부족 판단 근거를 그대로 보여줌 |
| 바뀐 이유 | 맞춤을 켰을 때 "안내방송을 1순위로 등록해서 점수가 올라갔어요" 한 줄 | 프론트 | 영상에서 개인화가 보이는 부분 |
| 사업장 무던한 시간 | 사업장 웹에서 등록한 요일 · 시간 · 조치 / 예) 화 10~12시 · 음악 끔 · 조명 낮춤 | 프론트 | 점수 계산에는 넣지 않고 따로 보여줌 |
| 이 장소 측정하기 | 이 장소로 정해진 채 측정 화면으로 | 프론트 |  |

## 5. 측정

### 측정 전

| 구성 요소 | 내용 | 영역 | 비고 |
|---|---|---|---|
| 측정 장소 | 위쪽에 "OO마트 신촌점에서 측정합니다" | 프론트 |  |

| 측정 시작 버튼 | 큰 버튼 하나. 아래에 "30초 동안 폰을 든 채로 계세요" | 프론트 |  |

| 소리 크기 | dB 숫자와 게이지 | 프론트 |  |

| 앱을 벗어났을 때 | 다른 앱으로 나가면 측정 취소. 돌아오면 "측정이 중단됐어요" | 프론트 |  |

## 8. 사업장 등록 웹 (앱과 별도)

로그인 · 사장 인증 없이 장소를 골라 바로 등록하는 시연용. 웹은 Supabase에 바로 붙고 서버 코드를 따로 짜지 않는다. 이 절의 "프론트"는 웹 화면.

### 장소 고르기 / 첫 화면
