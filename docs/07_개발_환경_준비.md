정해지지 않은 것을 지어내서 만들면 나중에 전부 다시 써야 한다.

## 2. 저장소 받기 (공통)

git이 없으면 먼저 설치: <https://git-scm.com>

```bash
git clone https://github.com/Jisub24/calm-map.git
cd calm-map
```

작업을 시작할 때마다 **먼저 최신 내용을 받는다.** 이것만 지켜도 충돌의 대부분이 사라진다.

```bash
git switch main
git pull
```

## 3. 키 파일 채우기 (공통)

`.env` 와 `local.properties` 는 **일부러 git에 올리지 않는다** (`CLAUDE.md` 원칙 7).
그래서 clone 해도 들어오지 않는다. 예시 파일을 복사해서 직접 채운다.

```bash
# Git Bash
cp android/local.properties.example android/local.properties
cp batch/.env.example            batch/.env
cp business-web/.env.example     business-web/.env
```

```powershell
# Windows PowerShell
Copy-Item android\local.properties.example android\local.properties
Copy-Item batch\.env.example            batch\.env
Copy-Item business-web\.env.example     business-web\.env
```

진짜 키 값은 팀 안에서 따로 전달한다. 누가 어떤 키를 갖는지:

| 키 | 앱 담당 | 분석 · 서버 담당 | 비고 |
|---|---|---|---|
| Supabase anon key | ○ | ○ | 권한 규칙 안에서만 동작 |
| Supabase **service key** | ✕ | ○ | 권한 규칙을 전부 무시하는 키. 앱 · 웹에 넣지 않는다 |
| 서울시 API 키 | ✕ | ○ | |
| 지도 SDK 키 | ○ | ✕ | |

GitHub Actions가 쓸 키는 저장소 **Settings → Secrets and variables → Actions** 에
`.env` 와 같은 이름으로 넣는다. 저장소에 파일로 올리는 것이 아니다.

## 4. 앱 담당 — Android Studio

### 설치

1. <https://developer.android.com/studio> 에서 받아 설치
   (내려받기 1GB 이상. `winget install Google.AndroidStudio` 로도 받을 수 있다)
2. 첫 실행 Setup Wizard
   - Import Settings → **Do not import**
   - Install Type → **Standard**
   - **SDK Location 은 공백이 없는 경로로.** 예: `C:\Android`
     (Windows 사용자 이름에 띄어쓰기가 있으면 기본 경로에 공백이 들어간다.
      일부 빌드 도구가 경로를 공백에서 잘못 끊어 읽는다)
   - License Agreement → 왼쪽 항목을 **하나씩 눌러 전부 Accept** 해야 Next 가 켜진다
3. "Sign in to Android Studio" 는 **Skip for now** (Gemini용이라 필요 없다)

### 프로젝트 열기

Android Studio → **Open** → `calm-map/android`

처음 열면 Gradle Sync 가 돌면서 라이브러리를 받는다. **첫 Sync 는 5~15분 걸린다.**
끝나면 상단 ▶ 버튼이 켜진다.

"Add Files to Git" 창이 뜨면 **Don't ask again 체크 후 Cancel**.
git 은 터미널에서 한 곳으로만 관리한다 (두 군데서 건드리면 꼬인다).

### 프로젝트 설정 (이미 정해진 값)

| 항목 | 값 |
|---|---|
| 템플릿 | Empty Activity (Jetpack Compose) |
| Package name | `com.calmmap` |
| Minimum SDK | API 26 (Android 8.0) — 기기 98.4% 지원 |
| Build configuration | Kotlin DSL (`build.gradle.kts`) |

### 에뮬레이터로 실행

Setup Wizard 가 가상 폰(`Medium Phone API 37.0`)을 하나 만들어 둔다.
상단에서 그 기기를 고르고 ▶ 를 누르면 빌드 → 설치 → 실행까지 자동으로 된다.
**첫 실행은 에뮬레이터 부팅에만 3~5분 걸린다.**

### 폰에서 실행

1. 폰 설정 → 휴대전화 정보 → **빌드번호를 7번 연속 탭** (개발자 옵션이 켜진다)
2. 설정 → 개발자 옵션 → **USB 디버깅** 켜기
3. USB로 PC에 연결 → 폰에 뜨는 "USB 디버깅을 허용하시겠습니까?" 허용
4. Android Studio 위쪽에서 기기를 고르고 ▶ 실행

APK 파일은 `android/app/build/outputs/apk/` 에 생긴다.
(`build/` 폴더는 빌드할 때마다 다시 만들어지는 중간 결과물이라 git에 올리지 않는다)

## 5. 분석 · 서버 담당 — Python

Python 3.10 이상. <https://www.python.org/downloads/>
(설치할 때 **Add Python to PATH** 를 반드시 체크)

### batch 준비

```bash
cd batch
python -m venv .venv
```

```bash
source .venv/Scripts/activate   # Git Bash
```
```powershell
.venv\Scripts\Activate.ps1      # PowerShell
```
```bash
pip install -r requirements.txt
```

`.venv` 는 **이 폴더 전용 Python 공간**이다. PC 전체에 라이브러리를 깔지 않아서
버전이 꼬여도 이 폴더만 지우고 다시 만들면 된다. git에는 올라가지 않는다.

> PowerShell에서 `Activate.ps1` 이 "실행할 수 없다"고 막히면 한 번만:
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

### batch 실행

```bash
cd batch
python collect_congestion.py
```

지금은 **일부러** `NotImplementedError` 를 내고 멈춘다.
반쯤 돌아가는 가짜 코드를 두면 "이게 되는 건가?" 하고 헷갈리기 때문에,
아직 안 만들었다는 것이 분명히 보이게 해 둔 것이다.

| 파일 | 하는 일 | 실행 주기 |
|---|---|---|
| `collect_congestion.py` | 서울시 API에서 지역 혼잡도 + 12시간 예측 수집 | 1시간 |
| `calculate_score.py` | 측정 라벨을 소리 종류 5개로 묶고 요소별 점수 계산 | 10~15분 |
| `forecast.py` | 시간대별 예측 + 상태 판정(단계 / 추정 / 정보 부족) | 10~15분 |
| `common.py` | 위 셋이 공통으로 쓰는 Supabase 연결 · 설정값 읽기 | — |

### 자동 실행 (GitHub Actions)

`.github/workflows/batch.yml` 에 틀이 있지만 **예약은 꺼 둔 상태**다.
스크립트가 비어 있는 지금 켜면 10~15분마다 실패 메일이 온다.
batch가 완성되면 `schedule` 앞의 `#` 을 지우면 켜진다.

### 분석 노트북

```bash
pip install jupyter
jupyter notebook
```

필요한 라이브러리는 **실험 01에서 정한다** — YAMNet을 TensorFlow Hub로 쓸지
TFLite로 쓸지 아직 정하지 않았다.

녹음 파일은 `analysis/recordings/` 에 두고 **git에 올리지 않는다.**
분석이 끝나면 지운다 (`CLAUDE.md` 원칙 1).
