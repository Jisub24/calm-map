# 디자인 원칙

와이어프레임: https://claude.ai/artifact/HpjZnZGUZd5TdgysyT6C9s (MVP 화면만. 팀원은 공유받아야 열림)

## 문구

| 원칙 | 예 |
|---|---|
| 권고형으로 | "오늘은 14시 이후가 무던합니다" / "아직 측정이 부족해서 안내하기 어려워요" |
| 판정형 금지 | "가면 안 돼요", "위험해요" 같은 표현 쓰지 않음 |
| 장소를 평가하지 않음 | 점수 순 정렬, "나쁜 가게", "시끄러운 가게" 같은 표현 쓰지 않음. 무던한 시간대를 앞에 |
| 개인정보 안내는 쉬운 말로 | "주변 소리는 녹음 · 저장하지 않고 소리 종류만 확인합니다" |

## 단계 표시

| 상태 | 표시 |
|---|---|
| 무던함 | 연한 진하기 + "무던" 글자 |
| 보통 | 중간 진하기 + "보통" 글자 |
| 붐빔 | 진한 진하기 + "붐빔" 글자 |
| 추정 | 테두리만 + "추정" (측정은 부족하고 혼잡도만 있을 때) |
| 정보 부족 | 회색 + 점선 테두리 + "정보 부족" |

색만으로 구분하지 않는다 (색각 이상 고려). 한 가지 색의 진하기로 단계를 나눈다. 붐빔을 빨강으로 표시하지 않는다.

## 색 — 후보 (미확정)

채도 낮은 차분한 색이 감각이 예민한 아이에게 부담이 적다는 방향의 자료가 있다. 자폐 스펙트럼 아동이 노랑 선호가 낮고 초록 · 갈색 선호가 높았다는 연구(Grandgeorge & Masataka, 2016)가 있다. 다만 표본이 작다.

| 용도 | 후보 |
|---|---|
| 배경 | #F7F4EE (따뜻한 미색) |
| 기본 색 | #A9C9DE (소프트 스카이블루) |
| 단계 무던 · 보통 · 붐빔 | #D6E6F0 · #8DB3CC · #3E6A8A |
| 버튼 · 강조 | #3E6A8A |
| 글자 | #2F2B28 |

주의할 점:
- 지도에서 물과 "내 위치" 점이 파란색이라 단계 표시가 묻힐 수 있다. 테두리와 글자로 확실히 구분한다.
- 연한 하늘색은 글자색으로 쓰지 않는다 (대비 부족).
- 쨍한 노랑 · 빨강 · 형광색은 피한다.

## 접근성

- 누르는 영역 최소 48dp
- 글자 크기는 폰 설정을 따른다
- 버튼은 실제 버튼 요소로 (스크린리더가 읽을 수 있게)
