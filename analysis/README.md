## 기종별 차이 (실험 3) — 결과

기준 기종은 **갤럭시 Z플립7 (SM-F766N)** — 앱이 실제로 쓰는 안드로이드 마이크 · 조도센서. 아이폰 15 로 잰 답사 7건을 그 단위로 바꾼다 (`settings.device_offsets`, 021).

| 항목 | 방법 | 결과 | 상태 |
|---|---|---|---|
| 소리 크기 | 갤럭시 기본 녹음 앱 · 아이폰 음성 메모를 거실에서 26분 동시 녹음. `device_compare.py` 로 0.1초 곡선을 맞춘 뒤 30초 Leq 차이 | 아이폰이 **1.2 dB 높게** 적음 (±1.0). 조용할 때와 시끄러울 때 같음. 라벨(Speech · 그릇)은 비슷하게 잡힘 | 확정 (앱 APK 로 한 번 더 확인 예정) |
| 조도 | ① 같은 방을 돌며 잰 두 폰의 값 분포 비교 ② 같은 자리에서 짝지어 측정 (천장 방향 2쌍 · 흰 종이 2쌍) | ① 아이폰 중앙값 915 ↔ 갤럭시 445 → 약 2배. ② 아이폰 카메라 값은 겨눈 면에 따라 2~5배 달라져(천장 462 · 흰 종이 1860) 비율 하나로 안 묶임 | 답사 7건에 **×0.5** 임시 적용. 답사 장소를 갤럭시 센서로 다시 재면 확정 |

```
python analysis/device_compare.py "테스트(아이폰).m4a" "테스트(갤럭시).m4a"
python analysis/lux_compare.py analysis/조도기종비교.csv
```
